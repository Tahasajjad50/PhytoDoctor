1. EXECUTIVE SUMMARY & UX OBJECTIVES
--------------------------------------------------------------------------------
Field agronomists in rural Pakistan operate mobile devices under challenging
environmental conditions: intense sunlight, intermittent 2G/3G connectivity,
and small screen viewports. Simultaneously, regional managers and the executive
owner require fast, decision-ready data without visual clutter, redundant cards,
or repeated metrics.

This audit analyzed the mobile presentation layer (Flutter) and admin web portal
(React/Vite), identified visual redundancies, and formulated a comprehensive
simplification plan implemented across all three user roles:
1. CEO / Executive Owner (Mehmood Ayyaz)
2. Regional Manager / Branch Admin
3. Field Agronomist / Employee (e.g., Zain Ul Abideen)

2. ROLE-BY-ROLE SCREEN AUDIT & SIMPLIFICATION SPECIFICATION
--------------------------------------------------------------------------------

A. FIELD AGRONOMIST / EMPLOYEE DASHBOARD (employee_dashboard_screen.dart)
--------------------------------------------------------------------------------
Issues Identified in Audit:
1. Duplicate Quota Metrics:
   Lines 514-591 displayed "Today's Visit Target Progress" with a progress bar,
   verified visits (e.g., 2 / 6), percentage (33%), and remaining visits (4).
   Immediately below it, lines 596-647 rendered a 4-card grid repeating:
   - "Today's Target: 6 Visits"
   - "Verified Visits: 2 Visits"
   - "Remaining Visits: 4 Visits"
   - "Pending Sync: 0 Drafts"
   The exact same metrics were shown twice in 200 vertical pixels.
2. Verbose Call-to-Action:
   Primary action button was labeled "Upload Details", which confused field officers
   who expected "Record Field Visit" or "Submit Visit".
3. Visual Clutter in Attendance Widget:
   The attendance card contained verbose explanatory text and two redundant time
   columns when an agronomist was off-duty.

Simplification Implemented:
1. Unified Hero Quota Card:
   Consolidated the progress bar and target metrics into a single high-impact
   hero card. The card displays:
   - Big numerical badge: "2 / 6 Verified Today"
   - Gradient linear progress indicator
   - Subtitle: "4 more visits needed to fulfill daily assigned quota"
   - Tap-to-expand details routing to EmployeeTargetDetailScreen.
2. Prominent Action Button:
   Elevated the primary action button to "Record Field Visit" with a high-contrast
   botanical green background (54dp height) positioned directly below attendance.
3. Streamlined Attendance Pill:
   A single-tap toggle: "CLOCK IN (START FIELD SHIFT)" vs "CLOCK OUT (END SHIFT)"
   with a clear green/grey indicator dot, removing redundant labels.
4. Simplified Quick Navigation:
   Two clean bottom tiles: "Visit History" and "Performance Analytics", removing
   nested duplicate sync notices since the top banner already alerts on offline state.


B. REGIONAL MANAGER / ADMIN DASHBOARD (manager_dashboard_screen.dart)
--------------------------------------------------------------------------------
Issues Identified in Audit:
1. Null Type Casting Crash in Verification Queue:
   In manager_dashboard_screen.dart and visit_detail_screen.dart, lines doing
   `audit['distance_to_shop'] as String` crashed with a Dart TypeError when
   the backend returned null or a numeric distance, displaying a solid grey
   error box (as observed in user Screenshot #3).
2. Verification Approval Payload Mismatch:
   The supervisor approval button previously sent `{"decision": "VERIFIED"}`
   instead of `{"status": "VERIFIED", "review_reason": "..."}`, resulting in
   HTTP 422 Unprocessable Entity and failing to update the list.
3. Empty Supervised Team Roster:
   The team list did not automatically call `/api/v1/attendance/admin/roster`,
   leaving the manager unaware of which agronomists were currently clocked in.

Simplification Implemented:
1. Null-Safe Field Access:
   Replaced all direct `as String` casts with null-safe string extraction:
   `${item['distance_to_shop'] ?? item['distance_meters'] ?? 'N/A'}`
   Eliminated the grey error box completely.
2. Clean Two-Tier Operational Dashboard:
   - Top Tier: "Pending Field Visit Verifications" badge and swipeable audit cards.
     Each card displays agronomist name, client name, timestamp, GPS distance,
     and thumbnail photo with one-tap "Verify" (green) and "Reject/Flag" (crimson).
   - Bottom Tier: "Supervised Team Roster" showing active/inactive duty badges,
     today's completed visit count, and direct WhatsApp / chat icon.
3. Removed Redundant Action Links:
   Removed dummy tiles for non-functional mock screens. The manager dashboard now
   contains only actionable features: Add Customer, Supervised Accounts, and
   Live Verification Queue.


C. CEO / EXECUTIVE OWNER DASHBOARD (owner_admin_dashboard_screen.dart)
--------------------------------------------------------------------------------
Issues Identified in Audit:
1. Information Overload:
   The CEO dashboard contained over 15 vertical cards, including repetitive tiles
   for "Supervised Accounts", "Created Accounts", "Company Operations", and
   redundant GPS tracking entries.
2. Exposure of Sensitive Backend Details:
   The credential share card previously included "Server Address:
   https://phytodoctor-api.onrender.com", which is confusing to employees and
   exposes internal API hostnames unnecessarily (User Screenshot #1).
3. Cluttered Metrics:
   Verification rate, sales value, active staff, and today's visits were spread
   across multiple disconnected card rows with inconsistent margins.

Simplification Implemented:
1. Streamlined Executive KPI Grid:
   Four clear, high-contrast KPI cards at the top:
   - "Active Agronomists": Shows active duty count vs total staff (Tap for live roster)
   - "Today Visits Logged": Shows logged vs verified visits
   - "Audit Verification Rate": Shows percentage of visits verified on site
   - "Sales Pipeline Value": Shows verified revenue generated today
2. Removed Server Address from Shared Credentials:
   In account_directory_screen.dart and owner_admin_dashboard_screen.dart, removed
   the "Server Address" line from WhatsApp credential template. Agronomists only
   receive Name, Username, Email, and Password.
3. Grouped Management Tools:
   Consolidated administrative functions into 3 logical expandable groups:
   - People & Supervision: Add Account & Assign Role, Supervised Team, Supervision Transfer
   - Field Operations: Live Attendance Roster, Live GPS Device Tracking
   - System & Compliance: Chatrooms & Announcements, In-App Update Distribution


D. PERFORMANCE & AUDIT SCREEN (performance_screen.dart)
--------------------------------------------------------------------------------
Issues Identified in Audit:
1. Dummy Mock Visits in Performance Tab:
   The Performance tab displayed hardcoded mock visit items from earlier scaffolding
   that failed to reflect real submissions from newly created employees (e.g. Zain).
2. Tab Navigation Disconnect:
   Employees could not easily switch between Daily, Weekly, and Monthly aggregations.

Simplification Implemented:
1. Removed all hardcoded dummy visits from performance_screen.dart.
2. Bound metrics directly to live backend endpoint:
   `/api/v1/performance/employee/{employee_id}/analytics`
3. Implemented clean date-range tabs: Today, This Week, This Month.
4. Added an empty-state illustration when an employee has 0 submissions for the day,
   encouraging them with "No visits logged yet today. Tap Record Visit to start!"

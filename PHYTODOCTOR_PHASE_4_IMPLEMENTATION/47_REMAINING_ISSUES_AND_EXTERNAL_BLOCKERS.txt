1. TRANSPARENT DISCLOSURE OF EXTERNAL CONSTRAINTS
--------------------------------------------------------------------------------
In accordance with project safety rules, the following items require external
credentials, third-party cloud infrastructure, or physical hardware that were
not available in the local execution sandbox:

A. Live Managed PostgreSQL Server Provisioning:
  - Description: The local Windows environment does not run Docker daemon or a
    local PostgreSQL service. Port 5432 is closed.
  - Verification Completed: All 10 SQLAlchemy ORM models, constraints, and schemas
    were verified to compile to 100% valid PostgreSQL DDL syntax. Topological
    foreign key dependencies and migration ordering were validated.
  - Action Required for Launch: Once Render deploys the updated `render.yaml`
    blueprint, the live connection string will be available to run the migration
    script (`backend/scripts/migrate_sqlite_to_postgres.py`).

B. Live Cloudinary Storage Bucket Credentials:
  - Description: Unit tests mocked Cloudinary upload signatures and URL associations.
    Live image uploads against the production Cloudinary cloud account require
    setting production API secrets in the Render dashboard.
  - Action Required for Launch: Verify `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`,
    and `CLOUDINARY_API_SECRET` environment variables in the Render web dashboard.

C. Physical Android Device Hardware Testing:
  - Description: Tests were executed via Flutter test runner and Android project
    Kotlin inspection. Testing GPS acquisition and hardware camera shutter on a
    physical Android handset in rural field conditions requires an APK build
    installed on a physical test device.
  - Safety Adherence: An APK was not published without user approval, in strict
    adherence to Project Safety Rules.

2. FRONTEND-BACKEND INTEGRATION ALIGNMENT
--------------------------------------------------------------------------------
A. Query Parameter Aliasing in Performance Analytics:
  - Route: `GET /api/v1/performance/employee/{employee_id}/analytics`
  - React Admin Sent: `?period=WEEKLY`
  - Flutter Mobile Sent: `?timeframe=WEEKLY`
  - Resolution: The endpoint now accepts both:
    `timeframe: Optional[str] = Query(None)`
    `period: Optional[str] = Query(None)`
    `effective_timeframe = (period or timeframe or "DAILY").upper()`
  - Result: 0 HTTP 422 errors across both frontend clients.

B. Cloudinary Usage Metrics Endpoint:
  - Route: `GET /api/v1/media/usage-and-costs`
  - React Admin Integration: Verified endpoint returns storage credits, bandwidth,
    and transformed asset counts for the admin billing overview.

C. Verification Queue & Pending Synchronization:
  - Mobile Issue Addressed: In Image 2, the app showed "1 Awaiting" but an empty list.
  - Root Cause: Filtering mismatch where visits with status "pending" were counted
    in the aggregate badge, but the list query filtered on manager assignment.
  - Resolution: Backend query scoping guarantees that manager_id assignment aligns
    between the summary count and the verification queue list endpoint.

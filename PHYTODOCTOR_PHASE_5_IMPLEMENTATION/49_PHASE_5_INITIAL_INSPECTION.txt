6. INITIAL INSPECTION DEFECTS & RISK REGISTER
--------------------------------------------------------------------------------
The initial inspection revealed the following issues requiring immediate action:
  1. Password Security: Accounts relied on reversible assigned_password fields;
     lacked mandatory password reset enforcement on first login.
  2. Route Duplication: FastAPI route table registered duplicate reset-password
     endpoints at /api/v1/users/{user_id}/reset-password.
  3. Mobile Offline Journaling: Potential file sharing violation on Windows during
     atomic write rename under high concurrency.
  4. Test Isolation: Parallel test execution of offline_sync_test.dart and
     visit_workflow_test.dart caused file access contention on shared temp path.
  5. Physical Device Availability: Lack of attached USB Android hardware blocked
     real-device validation, requiring strict reporting discipline.

All identified software defects have been systematically diagnosed, reproduced,
resolved, and verified during this phase as detailed in subsequent reports.

4. MULTI-ROLE END-TO-END BUSINESS WORKFLOW VERIFICATION
--------------------------------------------------------------------------------
Automated Test Evidence: backend/tests/test_end_to_end_business_workflows.py

[WORKFLOW 1] Employee Complete Field Workflow (test_employee_complete_field_workflow)
  1. Employee logs in via POST /auth/token (receives JWT).
  2. Clocks in with GPS coordinates and mandatory photo evidence (POST /attendance/clock-in).
  3. Queries active targets (GET /targets/my-targets).
  4. Records field visit with farmer profile, crop type, and coordinates (POST /visits/).
  5. Uploads photo evidence via Cloudinary pre-signed signature (POST /media/sign-upload).
  6. Checks shift status (GET /attendance/status).
  7. Clocks out at end of shift (POST /attendance/clock-out).
  - Verdict: PASSED (100% end-to-end execution success).

[WORKFLOW 2] Manager Supervision Workflow (test_manager_supervision_workflow)
  1. Manager logs in via POST /auth/admin-login.
  2. Queries pending supervision queue (GET /supervision/queue).
  3. Reviews submitted visit (GPS, photo, crop condition).
  4. Approves valid visit (POST /visits/{id}/verify).
  5. Rejects low-quality or fraudulent visit with notes (POST /visits/{id}/reject).
  6. Verifies employee target reflects verified count only.
  - Verdict: PASSED (100% end-to-end execution success).

[WORKFLOW 3] CEO Executive Workflow (test_ceo_executive_workflow)
  1. Owner/CEO logs in via POST /auth/admin-login.
  2. Views company-wide overview KPIs (GET /admin/dashboard/kpis).
  3. Batch assigns monthly target of 40 visits to all agronomists (POST /targets/batch).
  4. Provisions new field employee account (POST /users/).
  5. Inspects compliance audit logs (GET /admin/audit-logs).
  6. Dispatches company-wide broadcast announcement (POST /chat/rooms/{id}/messages).
  - Verdict: PASSED (100% end-to-end execution success).
